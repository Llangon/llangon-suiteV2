# Datos legales pendientes de confirmar

Documento creado para la renovación de la web pública de ASESORES LLANGON, S.L.

No se han incorporado datos legales o corporativos no confirmados en el proyecto público.

## Datos pendientes

- NIF/CIF de ASESORES LLANGON, S.L.
- Domicilio social.
- Dirección de contacto, si es distinta del domicilio social.
- Correo electrónico público de contacto.
- Teléfono público de contacto.
- Datos registrales.
- Responsable del tratamiento de datos.
- Correo o canal para ejercer derechos de protección de datos.
- Plazos de conservación aplicables al formulario de contacto.
- Encargados o destinatarios de datos, si existen.
- Texto definitivo de aviso legal.
- Texto definitivo de política de privacidad.
- Texto definitivo de política de cookies.
- Decisión sobre analítica web, si se incorpora.
- Dominio definitivo y política de indexación.

## Criterio aplicado

- No se han inventado direcciones, teléfonos, datos fiscales, miembros del equipo, certificaciones, clientes, testimonios ni cifras de experiencia.
- El formulario queda preparado visual y técnicamente, pero el envío definitivo requiere confirmar el canal de contacto y la política de privacidad.
- La web de prueba se configura como `noindex, nofollow`.
