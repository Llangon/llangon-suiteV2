# Datos legales pendientes de confirmar

Documento creado para la renovación de la web pública de ASESORES LLANGON, S.L.

Se han incorporado solo los datos legales y corporativos confirmados por ASESORES LLANGON, S.L.

## Datos pendientes

- Datos registrales.
- Confirmar si la dirección postal publicada coincide con el domicilio social.
- Responsable del tratamiento de datos.
- Confirmar si el canal para ejercer derechos de protección de datos será `info@llangon.com`.
- Plazos internos de conservación aplicables a consultas recibidas por email o teléfono.
- Encargados o destinatarios de datos, si existen.
- Decisión sobre analítica web, si se incorpora.
- Dominio definitivo y política de indexación.

## Criterio aplicado

- No se han inventado direcciones, teléfonos, datos fiscales, miembros del equipo, certificaciones, clientes, testimonios ni cifras de experiencia.
- La web publica no incorpora formulario de contacto. El contacto se realiza por email o teléfono.
- La web de prueba se configura como `noindex, nofollow` en meta robots, `robots.txt` y header `X-Robots-Tag`.
