# Datos locales

Esta carpeta se deja preparada para datos locales de ejecución, pero **no debe versionarse con contenido real**.

Quedan fuera del repositorio:

- bases de datos SQLite,
- claves locales,
- mensajes `.msg`,
- PDFs y TXT temporales,
- descargas operativas.

Si hace falta trabajar en local, crear aquí los datos necesarios sin subirlos a GitHub.
