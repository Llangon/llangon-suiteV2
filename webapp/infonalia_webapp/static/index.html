SMTP

Servidor SMTP

Servidor SMTP usado para enviar correos automáticos desde la suite.

La contraseña SMTP nunca se muestra en claro.

Modo pruebas: si está activo, la suite no debe enviar correos reales o los desvía según la lógica actual.

Destinatarios de avisos

Correo de aviso de ficha preparada: destinatario usado cuando una licitación pasa a estado Preparada.

Correos de seguimiento: direcciones usadas para avisos internos o seguimiento automático.

Telegram

Estado global y pruebas

Telegram permite enviar avisos al grupo general y a usuarios concretos sin mostrar nunca el token del bot.

Correo entrante

Acciones desde correo

Permite que la Suite lea órdenes enviadas por correo, como Descargar para ver o Preparar ficha. Si está desactivado, la Suite no procesará órdenes recibidas por correo.

Acciones por correo

Solo estos correos podrán enviar órdenes válidas. Separar varios por coma o salto de línea.

Almacenamiento

Dropbox Desktop

La carpeta base de Dropbox es donde la suite crea o localiza las carpetas de licitaciones. El modo fallback o legado indica que la suite está usando una ruta alternativa o histórica.

La prueba en seco simula operaciones sin modificar archivos reales.

IA documental

Estado y límites

La IA documental permite generar análisis o resúmenes internos de documentos de licitación. La clave de Gemini se gestiona por entorno y nunca se muestra.

IA documental

La clave Gemini se gestiona por entorno.

Automatismos

Scheduler y agenda

El scheduler ejecuta tareas automáticas como revisiones de correo, agenda o monitor. Aquí solo se editan destinatarios operativos de avisos.

Avisos operativos

Correo de agenda diaria: dirección que recibe el resumen diario de pendientes cuando el flujo automático está activo.

Inventario

Revisión interna de carpetas

El inventario interno revisa carpetas y rutas. La reconciliación intenta corregir rutas rotas cuando encuentra carpetas reales.

Zona avanzada

Diagnóstico seguro

Zona avanzada. Cambiar estas opciones puede afectar al funcionamiento de la suite. Algunos valores se muestran solo como diagnóstico porque dependen del equipo o de variables de entorno. Los secretos nunca se muestran en claro.
